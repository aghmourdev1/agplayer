Android Intent Integration

Use setPackage("com.aghmdev.agplayer") so Android resolves the correct activity automatically via the manifest intent-filter. No hard-coded activity class name needed.

AG Player must be installed on the user's device. You can check with packageManager.getPackageInfo("com.aghmdev.agplayer", 0) before firing the intent.
Kotlin — Single stream + headers + DRM 
val intent = Intent(Intent.ACTION_VIEW).apply {
    // Let Android find the right activity via its intent-filter
    setPackage("com.aghmdev.agplayer")
    data = Uri.parse("https://example.com/live/stream.m3u8")

    // Optional extras — all keys are case-insensitive in the parser
    putExtra("title", "Sports Channel HD")
    putExtra("user-agent", "Mozilla/5.0 (Linux; Android 14)")

    // HTTP headers as a JSON object string
    putExtra("headers", """{"Referer":"https://example.com","Cookie":"sid=abc123"}""")

    // Or pass headers as a pipe-separated string: "key1|value1|key2|value2"
    // putExtra("headers", "referer|https://example.com|cookie|sid=abc123")

    // DRM — JSON with "scheme" and "license" fields
    putExtra("drm", """{"scheme":"widevine","license":"https://license.example.com/wv"}""")

    // External subtitle file (.srt or .vtt)
    putExtra("subtitle", "https://example.com/subtitles.srt")

    // Thumbnail URL shown in mini-player
    putExtra("thumb", "https://example.com/thumb.jpg")
}
startActivity(intent)
Kotlin — DRM via individual extras (alternative) 
val intent = Intent(Intent.ACTION_VIEW).apply {
    setPackage("com.aghmdev.agplayer")
    data = Uri.parse("https://example.com/protected.mpd")
    putExtra("title", "Protected Movie")

    // DRM extras can also be passed individually:
    putExtra("drm_license_url", "https://license.example.com/widevine")
    putExtra("drm_scheme", "widevine")
    // drm_headers accepts a JSON string if your license server needs auth
    putExtra("drm_headers", """{"Authorization":"Bearer TOKEN"}""")
}
startActivity(intent)
Java — Single stream + headers + DRM 
Intent intent = new Intent(Intent.ACTION_VIEW);
intent.setPackage("com.aghmdev.agplayer");
intent.setData(Uri.parse("https://example.com/live/stream.m3u8"));

intent.putExtra("title", "Sports Channel HD");
intent.putExtra("user-agent", "Mozilla/5.0 (Linux; Android 14)");

// HTTP headers as JSON string
intent.putExtra("headers", "{\"Referer\":\"https://example.com\",\"Cookie\":\"sid=abc123\"}");

// Or pipe-separated: "key1|value1|key2|value2"
// intent.putExtra("headers", "referer|https://example.com|cookie|sid=abc123");

// DRM as JSON string
intent.putExtra("drm", "{\"scheme\":\"widevine\",\"license\":\"https://license.example.com/wv\"}");

// External subtitle
intent.putExtra("subtitle", "https://example.com/subtitles.srt");

startActivity(intent);

Web Deep Link Integration

Add a "Play in AG Player" button to any webpage using Android's intent:// scheme. Extras are passed as S.key=value parameters — Android unpacks them into the Bundle that IntentParser reads.

Works in Android browsers (Chrome, Firefox, etc.). The S. prefix tells Android to pass the value as a String extra into the Intent bundle.

Deep Link URL Structure

intent://example.com/stream.m3u8#Intent;scheme=https;type=video/*;package=com.aghmdev.agplayer;S.title=My%20Stream;S.user-agent=UA;S.headers=%7B...%7D;end
intent://host/path

Your stream URL without the https:// prefix

scheme=https

Restored as the URL scheme. Use http or https

type=video/*

MIME type — tells Android which activity to target

package=…agplayer

Restricts to AG Player only. Full package name required

S.key=value

String extras. Values must be URL-encoded. Use lowercase keys

HTML + JavaScript — play button with dynamic link building 
<!-- Simple static link -->
<a href="intent://example.com/stream.m3u8#Intent;scheme=https;type=video/*;package=com.aghmdev.agplayer;S.title=Live%20Stream;S.user-agent=Mozilla%2F5.0;end">
  🎬 Open in AG Player
</a>

<!-- JavaScript helper — builds the URL for you -->
<script>
function openInAGPlayer({ url, title, userAgent, headers, subtitle }) {
  const scheme = url.startsWith('https') ? 'https' : 'http';
  const host   = url.replace(/^https?:\/\//, '');

  let link = `intent://${host}#Intent;scheme=${scheme};type=video/*;package=com.aghmdev.agplayer;`;
  if (title)     link += `S.title=${encodeURIComponent(title)};`;
  if (userAgent) link += `S.user-agent=${encodeURIComponent(userAgent)};`;
  if (headers)   link += `S.headers=${encodeURIComponent(JSON.stringify(headers))};`;
  if (subtitle)  link += `S.subtitle=${encodeURIComponent(subtitle)};`;
  link += 'end';

  window.location.href = link;
}

// Usage:
openInAGPlayer({
  url:       'https://example.com/live/stream.m3u8',
  title:     'Sports Channel HD',
  userAgent: 'Mozilla/5.0 (Linux; Android 14)',
  headers:   { Referer: 'https://example.com', Cookie: 'sid=abc' }
});
</script>
The headers extra accepts either a JSON object string {"Referer":"..."} or a pipe-separated string referer|https://example.com. Both are handled by NormalizedHeaders.from().

URL Inline Headers

You can embed headers directly inside the stream URL using a pipe separator. AG Player detects and strips them before playback — useful for simple IPTV links or when you can't pass extras separately.

Format

https://example.com/stream.m3u8|key1=value1&key2=value2
URL part

The actual stream URL. Everything before the first |

| separator

Single pipe character splits URL from headers

key=value&key2=val2

URL-query-style headers. Keys are normalized to lowercase

Examples 
// Referer + User-Agent via URL pipe
val url = "https://example.com/stream.m3u8|Referer=https://example.com&user-agent=Mozilla/5.0"

// Authorization token via URL pipe
val url2 = "https://cdn.example.com/movie.mp4|Authorization=Bearer TOKEN123&Referer=https://example.com"

// DRM info can also be embedded as pipe headers:
val url3 = "https://example.com/protected.mpd|drmscheme=widevine&drmlicense=https://license.example.com/wv"

// Pass as the url extra or intent data — parser handles stripping automatically
val intent = Intent(Intent.ACTION_VIEW).apply {
    setPackage("com.aghmdev.agplayer")
    data = Uri.parse(url)
    putExtra("title", "My Channel")
}
startActivity(intent)
Headers embedded in the URL take lower priority than headers passed as a headers extra — if both are present, the extra wins.

Multiple Backup / Mirror Servers

Pass a JSON array via the servers extra. AG Player shows a server-selector inside the player so the user can switch sources without leaving.

Your App
servers JSON Array
AG Player
Server picker in player
Kotlin — Multiple servers with per-server headers 
val serversArray = JSONArray().apply {

    // Server 1 — Primary (4K)
    put(JSONObject().apply {
        put("name", "Server 1 — Main (4K)")
        put("path", "https://cdn1.example.com/live/4k.m3u8")
        put("headers", """{"Referer":"https://example.com"}""")
        put("user-agent", "Mozilla/5.0")
    })

    // Server 2 — Backup (FHD)
    put(JSONObject().apply {
        put("name", "Server 2 — Backup (FHD)")
        put("path", "https://cdn2.example.com/live/fhd.m3u8")
        put("headers", """{"Referer":"https://example.com"}""")
    })

    // Server 3 — Mobile (SD, no special headers)
    put(JSONObject().apply {
        put("name", "Server 3 — Mobile (SD)")
        put("path", "https://cdn3.example.com/live/sd.m3u8")
    })
}

val intent = Intent(Intent.ACTION_VIEW).apply {
    setPackage("com.aghmdev.agplayer")
    putExtra("title", "Live World Cup Match")
    putExtra("servers", serversArray.toString())
    // No data URI needed — the player uses the first server's "path" as the URL
}
startActivity(intent)

Intent Extras Reference

All supported extras — verified against IntentParser.java. All keys are normalized to lowercase.

Key Type Description Example
title String Title displayed in the player toolbar. Auto-derived from filename if omitted. "Sports Channel HD"
url String (URL) Stream URL as an explicit extra (alternative to setting intent.data) "https://…/stream.m3u8"
user-agent String HTTP User-Agent for all media network requests. Also extracted from headers if present. "Mozilla/5.0 (Linux; Android 14)"
headers String HTTP headers. Accepts: JSON object string {"{"}…{"}"} or pipe-separated string key|val|key2|val2 {"Referer":"https://…"}
drm JSON String DRM config: scheme (widevine/clearkey) + license (URL or key) + optional headers {"scheme":"widevine","license":"…"}
drm_license_url String DRM license URL as a standalone extra (also accepted: drmlicense, license) "https://license.…/widevine"
drm_scheme String DRM scheme as a standalone extra (also accepted: drmscheme, scheme) "widevine"
drm_headers JSON String HTTP headers sent to the DRM license server (e.g. Authorization token) {"Authorization":"Bearer …"}
subtitle String (URL) External subtitle file URL (.srt or .vtt) "https://…/sub.srt"
servers JSON Array String Array of server objects (name + path + optional headers/user-agent/drm). Replaces single URL. [{"name":"S1","path":"…"}]
thumb String (URL) Thumbnail / artwork image URL shown in the mini-player "https://…/thumb.jpg"
list JSON Array String A playlist of items to play sequentially (same structure as server objects) [{"title":"…","path":"…"}]
